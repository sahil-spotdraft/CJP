---

## 2. Elevator pitch

A customer org posts a feature request in Slack. Moonshot detects it and **notifies** the team in the hub. CS **triages** (match / create / dismiss). The ask becomes a tracked **Feature / Product Request**. When more orgs want the same thing, **Consolidation** rolls up ARR. **Analytics** Prize Score ranks what to build; **Roadmap** is where the journey ends as a product commitment.

## 3. Problem → solution (journey framing)

| Broken today | Moonshot journey |
|--------------|------------------|
| Ask dies in a customer Slack channel | Detected from the mapped org channel |

| Duplicate or lost tickets | **Triage** match / create / dismiss |
| Spreadsheet tracking | **Feature Requests** hub |
| One-off asks, no pattern | **Consolidation** across orgs + ARR |
| Gut-feel prioritization | **Analytics** Prize Score |
| Unclear commitment | **Roadmap** / status |
